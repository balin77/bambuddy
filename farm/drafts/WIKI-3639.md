````markdown
### Hiding Controls a Group Cannot Use

By default a control the user has no permission for is shown **greyed out**. That tells people the function exists, but for a helper who only clears plates and pauses prints, a printer card full of buttons that never work is noise. The group option **Hide controls this group cannot use** gives them a simpler Printers page ([#3639](https://github.com/maziggy/bambuddy/issues/3639)).

To switch it on, open the group in the editor (**Settings → Users → Groups**) and tick **Hide controls this group cannot use** at the bottom of the permission list, then **Save**. It is off by default, so nothing changes until you tick it.

Three rules:

- **All groups.** A user in several groups gets the simpler page only when **every one** of their groups has the option. One group without it keeps the full view.
- **Never for administrators.** Administrators always see every control. The Administrators group cannot have the option (the editor shows a note instead of the checkbox), and neither do installs with authentication off or API keys.
- **Display only.** It changes what members see, not what they may do. The server checks every permission exactly as before.

On the **Printers** page, a control that is disabled only because the user lacks the permission is left out: plate clear, the AMS slot actions, the entries of the card menu (edit, maintenance mode, delete), skip objects, the whole **Controls** section (light, movement, speed, pause, stop and so on), smart plug buttons, camera, files, **Print**, and on the page itself bulk select and **Add Printer**. A section with nothing left disappears too, so there are no empty frames or headings.

What stays:

- A control that is disabled for **another reason**, such as an offline printer or no print running, stays visible and greyed, so the card does not change shape.
- Temperature, fan and speed readings stay as plain readouts.
- In the **HMS errors**, **AMS Filament Backup** and **Firmware** dialogs the information stays (the faults, the unit list, the current version); only the buttons and switches the user cannot use, and the firmware version list, are left out.

!!! tip "Example: a helper group"
    Create a group "Helpers" with **Read Printers**, **Pause and resume** (or **Control Printers** with the finer permissions, see [Printer Control Permissions](#printer-control-permissions)) and **Clear Plate**, tick **Hide controls this group cannot use**, and the printer card shows the plate button and the pause button and little else.
````

Remove the tip's finer-permissions part if the wiki PR for #3248 has not been merged when this one is (the "Printer Control Permissions" section does not exist then).
