## Description

With Chrome's page translation on, for example on a phone whose browser language is Spanish, the UI soon fell back to the "UI Crash" screen with `NotFoundError: Failed to execute 'insertBefore' on 'Node': The node before which the new node is to be inserted is not a child of this node.` The translation rewrites text nodes React still owns; the next update inserts next to a node that is gone and throws.

Two changes, frontend only:

- `index.html`: `<html lang="en" translate="no">` and `<meta name="google" content="notranslate" />`. Bambuddy has its own language picker (#3625), so the page opts out of machine translation.
- `frontend/src/i18n/index.ts`: `<html lang>` follows the language in use (`i18n.on('languageChanged', …)`) instead of staying "en", so the browser no longer offers to translate a page that is already in the reader's language.

No backend change, no migration, no new dependency.
