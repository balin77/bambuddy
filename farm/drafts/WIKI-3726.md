### The AMS Picture

A **Load filament** entry draws the printer's AMS instead of a sentence ([#3726](https://github.com/maziggy/bambuddy/issues/3726)). Each AMS (and each AMS-HT, and the external spool) is a panel with its slots: colour, name and grams left. The filaments to load stand in a row inside the panel, **each directly above the slot it goes into**, with an arrow.

| Slot looks like | Meaning |
|---|---|
| amber frame, "out" | this spool is replaced (a short spool, or a slot nothing else needs) |
| dashed, "empty" | free slot |
| "fits" | a filament of the job is already there |
| lock, "printing now" | the running print uses it; never offered |

- The picture shows where Bambuddy would put each filament; it is the same decision as the slot lines of [Where to Put the Filament](#where-to-put-the-filament), only drawn.
- AMS units nothing goes into are folded: **Show AMS-B, C**. A dual-nozzle printer labels the nozzle a unit feeds. An AMS 3H wraps into rows of five.
- For a job queued for **Any &lt;model&gt;** the picture is that of the printer likely to take it first; the buttons above it switch to the other candidates.
- Prepare rows show a smaller picture.
- Grams come from the inventory spool assigned to the slot, otherwise the printer's own percentage. With Spoolman only the grams already known are shown, and no stock count.
- The picture follows the printer with the next scheduler pass (a few seconds).

### Assign the Spool in the Entry

**Assign spool for A3** lists the matching inventory spools inside the entry: spools with enough filament first, then by grams left, a spool that is too short dimmed with the reason. Each shows weight, state (new or opened) and storage location. **Assign** puts it into the slot. **Scan label** scans the spool's QR label into the same slot. **Add new spool** opens the spool form. **Set up slot** (a slot without RFID) opens the slot's type and colour dialog.

If the slot still holds the old spool, the entry reminds you to put the new spool in first.

!!! note "Permissions"
    Assign and Scan need `inventory:update`, Add new spool `inventory:create`, Set up slot `printers:control`. A group that hides controls it cannot use does not show them. With Spoolman, assigning uses Spoolman; while Spoolman is unreachable there is no assign button, and Add new spool is not offered.

### Acting on Other Entries

| Entry | Button | Permission |
|---|---|---|
| Printer did not power on | **Switch on again** | `smart_plugs:control` |
| Load filament, a filament missing | **Edit job**, **Move to another printer** (jobs pinned to a printer only) | `queue:update_all`, or `queue:update_own` for your own jobs |
| Load filament, none of that colour in the inventory | **Add spool** (built-in inventory) | `inventory:create` |

Edit job and Move open the queue's own edit dialog for the job.
