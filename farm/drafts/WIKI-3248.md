### 1b. New section

Insert **after** the `!!! tip "Separating Inventory Access from AMS Assignments"` block and before `### Ownership-Based Permissions`:

````markdown
### Printer Control Permissions

**Control Printers** (`printers:control`) allows every action that changes something on a printer. To let someone do only part of that, for example a helper who may pause and resume prints but not stop them, grant one or more of these instead ([#3248](https://github.com/maziggy/bambuddy/issues/3248)):

| Permission | Group editor label | Allows |
|------------|--------------------|--------|
| `printers:pause_resume` | Pause and resume | Pause and resume a print |
| `printers:stop` | Stop print | Stop a print, skip objects |
| `printers:filament` | Filament (load, unload, slot configure) | Load and unload filament, configure or reset an AMS slot or the external spool |
| `printers:tune` | Temperatures, fans, speed, light | Nozzle, bed and chamber temperatures, fan speeds, print speed, airduct mode, chamber light, Panda Breath |
| `printers:motion` | Move axes | Move the toolhead and bed, extrude and retract, home axes, select the active nozzle |
| `printers:drying` | Drying | Start and stop AMS drying, scheduled dryings |
| `printers:maintenance` | Calibration and maintenance | Start a calibration, change print options and AMS filament backup, clear HMS errors and run HMS actions |
| `printers:admin` | Connection and debug | Reconnect or disconnect a printer, turn MQTT logging on and off and clear it |

!!! info "Control Printers includes all of them"
    A group with **Control Printers** can do everything in the table, so existing groups and API keys keep working without any change. A single permission from the table allows only its own actions: it does not include Control Printers or the others.

In the **group editor** the eight permissions are listed indented under **Control Printers (includes the indented options)**. While Control Printers is ticked they show as ticked and greyed out (included); untick it to choose them one by one. **Files**, **AMS RFID** and **Clear Plate** are separate permissions, listed below them, and are not part of Control Printers.

On the printer card each control is enabled by its own permission: a user with only **Pause and resume** has Pause and Resume, while Stop, the temperatures and the movement controls stay disabled.

!!! note "What stays as it was"
    - The connection diagnostic and **Refresh status** need only **Read Printers**.
    - **API keys** with the *Control printer* option count as holding Control Printers for their owner. A key still cannot do more than its owner.
    - **Webhooks**: stop and cancel need Stop print; start, and commands from a slicer through a **virtual printer**, still need Control Printers.

!!! warning "Filament and slot labels"
    **Filament** lets a user change what an AMS slot or the external spool is labelled as, like Control Printers does. Keep that in mind for groups with [filament access](#filament-access) limits.

#### Example: a "Farm helper" group

A helper who keeps the farm running: watches printers, pauses and resumes a print, changes filament, and nothing else.

1. **Settings** → **Users** → **Groups** → **Add Group**, name it `Farm helper`
2. Tick **Read Printers**, **Pause and resume** and **Filament (load, unload, slot configure)**. Leave **Control Printers** unticked
3. Add the read permissions the helper needs (for example **Read Queue**, **Read Archives**), then **Save**

Members see the printers and can pause, resume, load and unload; Stop, temperatures, movement, drying, calibration and reconnecting are disabled for them.
````

### 1c. Existing tip about limited groups

In `### Filament Access`, the note ends with:

```markdown
    Don't give a limited group the **printers:control** permission: it lets members relabel an AMS slot or the external spool (for example set a PAHT-CF spool to PLA), and filament access reads the label the slot reports.
```

replace with:

```markdown
    Don't give a limited group the **printers:control** or **printers:filament** permission: either lets members relabel an AMS slot or the external spool (for example set a PAHT-CF spool to PLA), and filament access reads the label the slot reports.
```

No change: Operators keep Control Printers.
